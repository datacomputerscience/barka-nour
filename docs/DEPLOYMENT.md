# Deployment - Barka Nour to Cloudflare Pages

## Cloudflare Pages

Build config:
- Framework preset: Vite
- Build command: `npm run build`
- Build output directory: `dist`
- Node version: 20
- Root directory: / (or barka-nour if monorepo)

Files:
- `public/_headers`: security headers + cache immutable for /assets/*
- `public/_redirects`: API passthrough `/api/* /api/:splat 200`
- `public/_routes.json`: `{"version":1,"include":["/*"],"exclude":["/assets/*"]}` (generated by Vite? manual if needed)
- `public/404.html`: SPA fallback copy of index.html (Vite does not generate, we create minimal)
- `wrangler.toml`: `pages_build_output_dir = "./dist"` + name barka-nour + compatibility_date

Env vars in Cloudflare dashboard:
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`
- `VITE_META_PIXEL_ID`
- `VITE_APP_NAME=Barka Nour`
- `VITE_CURRENCY=TND`
- etc. (only VITE_ vars needed for client build)

Server secrets if using Functions/Workers:
- `SUPABASE_SERVICE_ROLE_KEY`
- `META_CAPI_ACCESS_TOKEN`
- `DELIVERY API KEYS`

## Build Local Test

```bash
npm run build
# dist/index.html 0.46kB
# dist/assets/index-*.css 42.45kB
# dist/assets/index-*.js 606.53kB
npx wrangler pages dev dist --port 8788
```

## Supabase Setup

1. Create project supabase.com (free)
2. SQL editor: run `src/database/migrations/001_initial_schema.sql`
3. Then `src/database/seeds/001_demo_data.sql`
4. Storage: create bucket `barka-nour-media` public, policy allow read
5. Copy URL + anon key to .env.local

## Custom Domain

- Cloudflare Pages -> Custom domains -> Add barkanour.tn
- DNS CNAME to pages.dev
- SSL auto

## Performance

- Cache: /assets/* immutable 1 year
- JS chunk 606kB - consider code splitting: `import()` for admin routes
- CSS 42kB - Tailwind purged
- Images: use Supabase Storage + CDN, object-only neutral background, WebP
